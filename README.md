# Superstore Sales Forecasting

This project explores how historical Superstore sales can be used to estimate future monthly sales and support business planning.
The analysis compares Linear Regression with Holt Winters forecasting. Holt Winters had lower errors on the test data, so it was selected to produce a six month forecast for January to June 2018.
The forecast and model results are historical examples based on data ending in 2017. They are not predictions of current sales.
See the project report for the forecast chart, results, and discussion of business use and limitations.
